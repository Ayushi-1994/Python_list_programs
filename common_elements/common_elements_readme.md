PROGRAM: Common Elements in Two Lists

PROBLEM:
Find common elements between two lists.

INPUT:
[1, 2, 3, 4]
[3, 4, 5, 6]

OUTPUT:
[3, 4]

LOGIC:
1. Traverse first list.
2. Check if element exists in second list.
3. If found, add to result.
4. Print all common elements.

TIME COMPLEXITY:
O(n²)

SPACE COMPLEXITY:
O(n)
