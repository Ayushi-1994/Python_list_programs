PROGRAM: Remove Duplicates from List

PROBLEM:
Remove duplicate elements while preserving original order.

INPUT:
[1, 2, 2, 3, 4, 4, 5]

OUTPUT:
[1, 2, 3, 4, 5]

LOGIC:
1. Create an empty result list.
2. Traverse the original list.
3. Add element only if it does not already exist.
4. Return the result list.

TIME COMPLEXITY:
O(n²)

SPACE COMPLEXITY:
O(n)
