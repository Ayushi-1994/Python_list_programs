PROGRAM: Find Second Largest Element

PROBLEM:
Find the second largest element without sorting the list.

INPUT:
[10, 20, 40, 30, 50]

OUTPUT:
40

LOGIC:
1. Maintain largest and second largest variables.
2. Update both while traversing the list.
3. Largest stores maximum element.
4. Second largest stores second highest element.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(1)
