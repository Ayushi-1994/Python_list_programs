PROGRAM: Frequency Count of Elements

PROBLEM:
Count occurrence of every element in a list.

INPUT:
[1, 2, 2, 3, 3, 3]

OUTPUT:
{1:1, 2:2, 3:3}

LOGIC:
1. Create empty dictionary.
2. Traverse list.
3. Update count for each element.
4. Dictionary stores frequencies.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(n)
