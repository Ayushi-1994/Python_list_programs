PROGRAM: Move Zeros to End

PROBLEM:
Move all zeros to end while maintaining order of non-zero elements.

INPUT:
[1, 0, 2, 0, 3, 4]

OUTPUT:
[1, 2, 3, 4, 0, 0]

LOGIC:
1. Store non-zero elements.
2. Count removed zeros.
3. Append zeros at end.
4. Preserve original order.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(n)
