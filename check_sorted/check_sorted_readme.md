PROGRAM: Check if List is Sorted

PROBLEM:
Determine whether a list is sorted in ascending order.

INPUT:
[1, 2, 3, 4, 5]

OUTPUT:
True

LOGIC:
1. Compare every element with next element.
2. If current element is greater than next, list is not sorted.
3. Otherwise continue checking.
4. If all comparisons pass, list is sorted.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(1)
