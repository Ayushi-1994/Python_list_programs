PROGRAM: Find Missing Number

PROBLEM:
Find the missing number from 1 to N.

INPUT:
[1, 2, 3, 5]

OUTPUT:
4

LOGIC:
1. Calculate expected sum using formula n(n+1)/2.
2. Calculate actual sum of list.
3. Difference between both sums is the missing number.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(1)
