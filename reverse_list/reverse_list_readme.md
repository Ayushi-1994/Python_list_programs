PROGRAM: Reverse a List

PROBLEM:
Reverse a list without using reverse() function.

INPUT:
[1, 2, 3, 4, 5]

OUTPUT:
[5, 4, 3, 2, 1]

LOGIC:
1. Use two pointers.
2. One starts from beginning and one from end.
3. Swap both elements.
4. Move pointers toward center.
5. Continue until pointers meet.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(1)
