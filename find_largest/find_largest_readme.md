PROGRAM: Find Largest Element in a List

PROBLEM:
Find the largest element from a list without using max().

INPUT:
[10, 20, 5, 40, 25]

OUTPUT:
40

LOGIC:
1. Assume first element is largest.
2. Traverse through the list.
3. If current element is greater than largest, update largest.
4. After traversal, largest contains the maximum value.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(1)
